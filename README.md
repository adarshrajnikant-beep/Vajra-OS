# Vajra OS 🇮🇳

**An Indian, AOSP-based mobile operating system.**

Vajra OS is an independent effort to build a mobile operating system rooted in India — designed to compete with the likes of iOS and Samsung's One UI, while staying open, lightweight, and privacy-respecting.

---

## 🎯 Vision

India has the world's largest smartphone user base, yet runs almost entirely on foreign operating systems. Vajra OS aims to change that — a system built by Indians, for the world, starting from the Android Open Source Project (AOSP) foundation and evolving into something distinct.

## 🚀 Goals

- Build a custom Android-based OS on top of AOSP
- Prioritize privacy, performance, and a clean user experience
- Design original UI/UX — not a copy of stock Android
- Keep it lightweight and optimized for a wide range of devices
- Eventually offer it as a licensable OS for device manufacturers

## 🗺️ Roadmap

- [ ] **Phase 1 — Custom Launcher** (Kotlin/Android app, current focus)
- [ ] **Phase 2 — System Apps** (dialer, messages, settings, camera)
- [ ] **Phase 3 — AOSP Build** (full custom ROM, flashable)
- [ ] **Phase 4 — Device Partnerships**

## 📂 Project Structure

- `docs/` → planning notes, research, design docs
- `launcher/` → custom launcher app source code
- `assets/` → logo, icons, branding

## 🛠️ Tech Stack (planned)

- **AOSP** (Android Open Source Project) — base
- **Kotlin / Java** — app & launcher layer
- **C/C++** — system-level components
